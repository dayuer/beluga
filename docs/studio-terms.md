# Synon Studio 客户条款（P1）

版本：P1 · 2026-11-11。这一页写给**使用 Synon Studio 的客户**。运营方在给第一个真实客户开通之前定稿并附在
邀请里；运营手册是 [`docs/studio.md`](studio.md)。

## 1. 你在用的是什么

Synon Studio 让你在 Web（手机宽度优先）上把需求交给**运营方的工作室**：运营方的 Beluga daemon 和它的 AI
团队把需求变成一份计划，你确认计划、和规划 agent 对话、回答决策、验收里程碑。**AI 在运营方的机器上跑，
不使用你的账号，也不在你的设备上执行任何东西。** 开工由运营方批准；P1 的交付/预览 Gate 在 P2。

## 2. 中台能看到什么、看不到什么

中台不做端到端加密；传输走 TLS。中台是一个小型服务（Cloudflare Worker + D1 + 每个工作室一个 Durable
Object），保存你要看的那份数据：

| 数据 | 中台存不存 | 保留期 | 谁能读 |
|---|---|---|---|
| 你的账号（邮箱、名字、所在项目） | 存（D1） | 账号存在期间；删除账号后 30 天内清除 | 运营方 |
| 客户视图（计划文字、决策、动态、验收结论） | 存最新一份缓存 | 项目存在期间；项目删除即清除 | 运营方 |
| 对话 turns（你和计划 agent 的对话） | 存（最近部分 + 分页历史） | 项目存在期间；删除账号或项目时清除 | 运营方 |
| 动作队列（你发出的需求/消息原文） | 存 | 7 天 | 运营方 |
| opId 去重表（只有 id 和结果码，不含正文） | 存 | 不短于 14 天 | — |
| 日志 | 只记帧类型、大小、错误码，不记正文 | 30 天 | 运营方 |
| 源代码、diff、密钥 | **永远不存**，daemon 不发 | — | — |

- **运营方（和你授权的人）能读你与计划 agent 的对话，以及计划文字**；客户视图里的文字已经过净化器，
  路径、分支、模型名、任务 KEY、代码块与密钥不会出现在里面。
- 子处理方：**Cloudflare**（Worker、Durable Object、D1，全球节点，可能跨境）；**魔法链接的邮件发送方**
  （由运营方选择，例如 Resend）。
- **动作队列会保留 7 天**，因为运营方的 daemon 可能离线，动作要等它回来；这是你的输入，不是从运营方机器
  上带出来的代码或密钥。
- P1 不存预览产物。**P2 的预览/交付物会带前端代码**（Web 预览的 JS 包就是前端源代码，APK 可以反编译）；
  预览是交付物、是你买的 app 本身，不属于上面“永远拿不到源代码”的范围，P2 的条款会再写明。

## 3. 你的登录与数据

- P1 没有注册页：运营方邀请你的邮箱，你收到一次性魔法链接（15 分钟有效），登录后得到 30 天的会话。
- 你的会话可以随时由运营方移除；移除后你的连接立即失效。
- **删除账号**：P1 由你联系运营方，运营方在管理页删除；中台清除该账号的数据（成员关系、令牌、会话、待发
  邮件）。P2 起你也可以在设置屏自己发起（iOS 审核要求）。运营方机器上的代码仓库按你们之间的合同处理。

## 4. 我们不做什么

- 不做端到端加密；中台按上表能读到计划文字与对话。
- 不把你的账号或需求用于训练模型。
- 不在你的设备上运行 agent，也不需要你的 Claude/其他账号。
- P1 没有推送和邮件通知；需要你回来时，运营方会直接联系你。P2 加推送时会单独给出通知时机表。
- P1 不收费（Stripe 在 P3）；没有价格、购买按钮或外链。

推送、预览与交付 Gate 时会先更新这一页。
