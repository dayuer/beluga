# Synon Studio 隐私说明

适用：Synon Studio 手机应用（iOS、Android）。最后更新：2026-11-21。

你是工作室的客户。这份说明写清楚应用收集什么、为什么收集、存在哪里、什么时候删除，以及你能怎么处理。
应用内同一份说明在「我 › 账号 › 隐私说明」；两者内容一致，以本文件为准。

## 1. 我们收集什么

| 类别 | 具体内容 | 什么时候 |
|---|---|---|
| 账号 | 邮箱地址 | 登录、接收回执 |
| 登录凭证 | 登录后由中台签发的会话令牌（存在本机安全存储） | 登录后 |
| 需求内容 | 你写的需求正文、追问回答、语音转写的文字 | 你提交需求或回复时 |
| 附件 | 你选择或拍摄的图片、设计稿、文件 | 你添加附件时 |
| 设备密钥 | 本机生成的签名密钥（私钥只在本机安全存储，不离开手机） | 设备登记时 |
| 推送 | 设备标识（本机随机生成）、平台（iOS/Android）、APNs/FCM 设备令牌 | 开启推送通知时 |
| 签名记录 | 你批准开工、通过交付、批准上线等动作与时间 | 你签名时 |

## 2. 我们不收集什么

- 不收集通讯录、位置、健康与运动数据、短信、通话记录、剪贴板内容。
- 不读取相册全部内容：只有你主动选择附件时，才读取你选中的那几张。
- 不做广告投放、用户画像，不向第三方出售或共享你的个人信息。
- 不在后台持续录音：麦克风只在你按住说话时使用，转写完成后音频不保留。

## 3. 用来做什么

1. 完成你委托的需求：把需求与附件交给你的工作室的 Beluga 节点处理。
2. 通知进展：待你确认、交付完成、上线结果，经系统推送提醒你。
3. 签名与审计：记录谁在什么时候批准了什么，作为交付凭据。
4. 排障与支持：在你要求时，用会话与需求编号定位问题。

## 4. 存在哪里、怎么传输

- 手机与中台之间使用 HTTPS / WSS 加密传输。
- 中台（Cloudflare）承载登录、需求转发与推送令牌，数据可能跨境处理。
- 需求与代码在你的工作室自己的 Beluga 节点上处理；节点由工作室管理。
- 本机的会话令牌与设备私钥存放在系统安全存储（iOS Keychain / Android Keystore）。

## 5. 保留多久

- 账号与需求：账号存续期间保留；你要求删除后，除法律要求保留的交付与签名记录外，在 30 天内清除。
- 推送令牌：关闭通知或退出登录时注销；注销失败的记录在下次登录时补删。
- 设备私钥：只在本机；卸载应用或移除设备即失效。
- 签名与交付记录：为交付凭据与法律要求保留；具体期限由你的工作室与合同约定。

## 6. 设备权限

| 权限 | 用途 | 不开会怎样 |
|---|---|---|
| 相机 | 扫描配对二维码、拍摄图片附件 | 可用相册选择图片 |
| 麦克风 | 录一段语音说明需求（转成文字） | 打字提交需求 |
| 相册 | 选择图片或设计稿作为附件 | 不能添加图片附件 |
| 通知 | 待你确认、交付完成时提醒 | 仍可在应用内看到 |

权限可随时在系统设置里关闭；关闭后应用不会再做相应的采集。

## 7. 你的选择

- **查看与更正**：邮箱、语言、外观在「我 › 账号」里查看与修改；需求内容可在需求详情里查看。
- **撤回同意**：关闭系统权限即停止相应采集；关闭推送开关即注销本机令牌。
- **删除账号**：手机端暂未开放删除入口，请联系你的工作室，或在桌面端操作。删除后按第 5 节处理。

## 8. 联系我们

隐私问题、数据查询或删除请求：`privacy@synon.studio`。我们会在 15 个工作日内答复。

## 9. 变更

这份说明更新时，会同时改应用内「我 › 账号 › 隐私说明」和本文件，并在应用更新说明里写清楚改了什么。
涉及新增收集类别时，会在使用前单独征得你的同意。
