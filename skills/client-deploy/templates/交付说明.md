## 2. 怎么让应用上线

把 `部署包/` 交给你的运维,让他从 `部署说明.md` 开始看。需要:一台装了 Docker 的服务器,想要 `https://` 的话再加一个域名。
整个过程不需要把任何密码发给我们。

## 3. 日常使用

- 打开你的网址就能用;手机浏览器里选"添加到主屏幕",以后像 App 一样打开。
- 数据默认保存在使用者自己的浏览器里,换手机或清除浏览器数据,数据会丢失。需要多人共享数据,要让我们加后端——这是一次新的开发。

## 4. 以后想改应用

1. 把 `源码/{{NAME}}.bundle` 交给程序员。他执行:`git clone {{NAME}}.bundle {{NAME}}` 就得到完整的代码和所有历史版本。
2. 代码是 TypeScript + Vite 的普通网页项目;`README.md` 里写了每个功能在哪个文件。
3. 改完执行 `npm install && npm run build`,把生成的 `dist/` 文件夹放到服务器上(或重新打包后按 `部署说明.md` 的 Docker 方式更新)。

## 5. 想回到以前的版本

在 `历史版本.md` 里找到版本名。源码里每个版本都有标记(git tag),程序员用 `git checkout <版本名>` 就能看到当时的样子,再重新构建和部署。

## 6. 账号和所有权(请你自己保管)

- **代码**:现在归你,上面的 bundle 就是完整副本。如果代码在 GitHub 上,我们会按你的选择把仓库转给你的账号。
- **域名、服务器、云账号**:一直是你自己的,我们没有、也不会拿到你的密码。请你把这些账号的登录信息保存好,不要发到聊天里。
- 部署包里没有任何密钥;可调整的设置只有 `部署包/.env.example` 里列的几项。

## 7. 遇到问题

- 打不开:先看 `部署包/部署说明.md` 最后的"打不开怎么办"。
- 想加功能:把想法告诉我们,我们会像做第一版那样先和你确认需求。
